PROJECT INFORMATION

About BWH

BWH is a bilingual, rule-based web application for technical troubleshooting education and reference.

Architecture

The current release is a static PWA prototype. Its diagnostic decisions are explicit JavaScript rules and curated JSON knowledge records. No AI model is included.

Cloud deployment

Deploy the folder to any HTTPS static hosting provider. HTTPS is required for service worker installation in production (localhost is also supported for development).

Next development steps

  • Expand and verify the technical knowledge base.
  • Add references and version metadata to each solution.
  • Add optional user accounts and cloud synchronization only if needed.

Safety boundaries

Commands are guidance only. BWH does not execute commands, request domain credentials, or establish a connection to company infrastructure.
